# palco-updates

Canal público de auto-update do Palco Receiver (fallback até distribuição oficial nas lojas).

- `manifest.json` — versão corrente + path do HTML
- `<version>/index.html` — receiver completo da release

Servido por GitHub Pages. Publicado automaticamente pelo CI do [palco-receiver](https://github.com/pianolouvorja/palco-receiver) em tags `v*`.
